How to publish a new painting:
  1. Upload your photos into the assets folder on GitHub first (main photo + any close-ups, e.g. golden-summer-fields.jpg, golden-summer-fields-2.jpg).
  2. Fill in this form using those file names.
  3. Click Generate Entry, then Copy.
  4. On GitHub, open data/paintings.json → pencil icon → paste the new entry after the previous painting's closing }, → Commit changes.
